## About

I study Information Systems at UNIRIO and work as a software development intern at **Bagaggio**, where 200+ stores rely on tools I built or still maintain. Before that, I freelanced with Next.js and built educational games at the university.

What really interests me is what happens when things go wrong: two requests racing for the last item in stock, a worker dying mid-job, a coding agent editing a file nobody asked it to touch.
